# Основные команды Git

# Основные команды Git

## git init
Создает новый репозиторий в текущей папке

```bash
git init
```

## git status
Показывает состояние файлов

```bash
git status
```

## git add
Добавляет файлы в индекс для коммита

```bash
git add .
git add filename
```

## git commit
Сохраняет изменения в истории

```bash
git commit -m "Сообщение"
```

## git log
Показывает историю коммитов

```bash
git log
git log --oneline
```
